O que cada CNC vai sugerir

Fila de produção (OPs abertas)

Arraste as linhas (ou use ▲ ▼) para definir a ordem. Em Máquina, "Qualquer" deixa a OP na fila das duas CNCs. O operador vê a lista inteira e pode escolher outra OP, se precisar.

Previsão detalhada por máquina

Tempo de cada OP = tempo/peça × quantidade − o que já foi trabalhado. Tempo/peça: Padrão (média dos últimos 5 lotes do mesmo código) ou, se o código nunca foi usinado, o Previsto pelo PCP. OPs com máquina "Qualquer" vão para a máquina que fica livre primeiro. O relógio só avança nos turnos de segunda a sexta (07h às 06h30 do dia seguinte); sábado não entra.

Tempos por código de peça

O tempo previsto só é usado enquanto o código não tiver lote encerrado. Depois vale o padrão real.
